# Definition of Done

A story is Done when:
- Acceptance criteria are implemented.
- Code has been reviewed.
- Relevant unit/integration checks pass.
- API tests pass where applicable.
- Required Playwright regression scenarios pass.
- Manual exploratory testing is completed where appropriate.
- No unresolved P0/P1 defect blocks release.
- Traceability is updated.
- Documentation is updated.
- CI pipeline is green.
