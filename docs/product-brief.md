# Product Brief — CaseFlow

## Problem
Administrative teams often need a simple way to create, assign, track and audit cases or documents without relying on disconnected spreadsheets, messages and manual status tracking.

## Product
CaseFlow is a fictitious web application for managing cases and documents through a controlled workflow.

## Primary users

### Operator
Creates, searches and updates cases assigned to them.

### Administrator
Manages users, permissions, assignments and global visibility.

## Core capabilities
1. Authentication
2. Role-based access
3. Case/document creation
4. Assignment to responsible users
5. Status transitions
6. Search and filtering
7. Audit history
8. Dashboard metrics

## Initial workflow
```text
Created -> Assigned -> In Progress -> Completed
                  \-> Rejected
```

## Non-goals for the MVP
- Real judicial data
- Real citizen information
- Production messaging integrations
- Complex billing
- Mobile native application

## Portfolio objective
Demonstrate a realistic end-to-end Quality Engineering lifecycle using Jira, MCP, Playwright, API testing, GitHub Actions, Docker and AWS.
